# Bouwen met Copilot Code

Gebruik Copilot Code wanneer je een kleine werkende oplossing nodig hebt en kunt beschrijven wat die moet doen, zoals een hulpmiddel om teamverzoeken bij te houden. Controleer of een bestaande dienst al aan de behoefte voldoet voordat je een nieuwe toepassing maakt.

Microsoft beschrijft Code als een manier om met gewone taal oplossingen te bouwen zonder eerdere programmeerervaring. Toegang vereist deelname aan Frontier, een ondersteund account of een geschikte licentie en een ingeschakeld Code-tabblad. Een GitHub-account of GitHub Copilot-licentie is niet vereist. Lees [Microsofts leermodule over Copilot Code](https://learn.microsoft.com/nl-nl/training/modules/build-solutions-copilot-code/) voor de actuele voorwaarden.

## Beschrijf de behoefte voordat je bouwt

Leg vast wie de oplossing gebruikt, welke informatie nodig is, welke acties mogelijk moeten zijn en hoe je vaststelt dat de oplossing werkt. Bepaal de gezaghebbende gegevensbron en wie die mag wijzigen. Begin met één volledig werkend pad. Test daarna uitzonderingen, zoals ontbrekende informatie of een gebruiker zonder toegang.

Vergelijk [Agent Builder en Copilot Studio](./build.md) voor een agent die vragen beantwoordt of een beheerd proces uitvoert. Vergelijk [GitHub Copilot en Microsoft Foundry](./develop.md) voor een softwareproject dat een ontwikkelteam en eigen AI-diensten nodig heeft.

## Controleer de oplossing en wijs een eigenaar aan

Ik raad aan de eerste versie met voorbeeldgegevens te testen voordat je gevoelige informatie koppelt of de oplossing met een team deelt. Controleer resultaten, toegang, foutafhandeling en waar de toepassing en gegevens komen te staan. Spreek af wie onderhoud en ondersteuning verzorgt, wijzigingen beoordeelt en de oplossing uitfaseert als de behoefte vervalt.

:::warning[Controleer voordat je deelt]

Een werkend prototype vraagt nog om beoordeling. Laat de verantwoordelijken gegevenstoegang, bedrijfsregels en ondersteuning controleren voordat anderen ervan afhankelijk worden.

:::

## Controleer previewtoegang en kosten

Code is een Frontier-ervaring met vroege toegang. Controleer de beschikbaarheid in je omgeving voordat je een uitrol plant. Microsoft plaatst Code onder [facturering naar verbruik met Copilot Credits](https://learn.microsoft.com/nl-nl/microsoft-365/copilot/user-subscription-license-usage-based-billing). Controleer de toepasselijke licentie, het uitgavenbeleid en eventuele kosten voor het draaien van de gemaakte oplossing. Gebruik [Licenties en kosten](./licensing-and-costs.md) om die kosten met de eigenaar te bespreken.
