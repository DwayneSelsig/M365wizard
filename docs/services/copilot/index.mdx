# Copilot

Start with the work: get help, delegate a task, build a solution, or automate ongoing work. I use four modes of work in Copilot:

- **Assist:** Ask, draft, and analyze with Chat.
- **Delegate:** Assign Cowork a multistep task and review the result.
- **Build:** Create your own solution with Code by describing what it should do.
- **Automate:** Give Autopilot an ongoing goal within agreed boundaries.

Microsoft brings Chat and Cowork together in Home. Code and Autopilot add building and ongoing work to that experience. See [Microsoft's September 25, 2026 announcement](https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/). Access depends on the feature, license, and preview terms.

- **[Agent Builder](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-builder) is no-code:** Configure instructions and knowledge sources without writing code. Start here for a focused agent that answers questions for you or a small team.
- **[Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/fundamentals-what-is-copilot-studio) is low-code:** Build with visual tools, connectors, and reusable components, with custom code where needed. Choose it when the agent needs actions, wider publication, integrations, or a managed production lifecycle.

I recommend low-code when the available building blocks fit the process. [Compare the building options](./build.md).

With **pro-code**, a development team writes and maintains software with code, APIs, and SDKs:

- **[GitHub Copilot](https://docs.github.com/en/copilot/get-started/about-github-copilot) supports pro-code development:** It helps developers write, explain, test, and review code.
- **[Microsoft Foundry](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/overview-custom-engine-agent) supports pro-code AI solutions:** Use it to build and operate AI applications, agents, and models on Azure, with your own logic and integrations.

A team may use both: GitHub Copilot for application code and Foundry for the AI runtime and evaluation. Choose pro-code when custom logic or control over models and orchestration justifies the development work and a team can maintain it. A solution can combine this code with low-code components. [Compare the development options](./develop.md).

## Before You Expand Use

Assign an owner, test the solution, and arrange support before others rely on it. Check the quality and ownership of the information AI will use. Review access, expected human checks, support, and the cost of repeated or long-running work. Start with [Permissions And Ownership](../../admin-and-governance/permissions-and-ownership.md) and [Microsoft Purview](../purview.md); use [Copilot Studio agent governance](../../admin-and-governance/govern-copilot-studio-agents.md) when an agent becomes an organizational service.
