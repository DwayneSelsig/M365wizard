# Copilot

**What do you want AI to do?** Start with the work: get help with a question, delegate a task, build an agent for a recurring need, or develop an AI solution. I use these four directions to choose a starting point. The same task may fit more than one product.

- **Assist:** Ask, draft, analyze, or work with your Microsoft 365 context.
- **Delegate:** Give AI a task with a result to review, or arrange work that continues over time.
- **Build:** Make an agent around knowledge or a process without starting a software project.
- **Develop:** Write software with AI assistance or build an AI-powered application.

Assist and Delegate mainly help people work more effectively themselves. Build and Develop help an organization create reusable solutions. The products do not represent required maturity levels. A simple question can still belong in Copilot Chat in an organization that also develops advanced agents.

Start here when you want an answer, a draft, or help with your own work. Copilot Chat can use information you provide and capabilities included with an eligible Microsoft 365 subscription. Microsoft 365 Copilot adds licensed work-context experiences across supported Microsoft 365 content and apps. Agents can also make selected organizational data available in Copilot Chat, so the boundary is not absolute. [Compare the assistance options](./assist.md) and [check the licensing model](./licensing-and-costs.md).

Start here when the desired result takes several steps. Cowork carries out a task you assign and lets you review its work. Autopilot is intended to keep working toward a goal across time with less continuous prompting. More autonomy calls for clearer boundaries, ownership, and review. Autopilot is in private preview, so do not plan an ordinary rollout around it. [Compare delegation options](./delegate.md).

Choose Copilot Studio when the agent needs actions, wider publication, integrations, or a managed production lifecycle. Both can create agents; the audience and operating needs decide where to build. A development team may use both: GitHub Copilot while writing the application and Foundry for its AI runtime and evaluation. [Compare the development options](./develop.md).

## Before You Expand Use

Check the quality and ownership of the information AI will use. Review access, expected human checks, support, and the cost of repeated or long-running work. Start with [Permissions And Ownership](../../admin-and-governance/permissions-and-ownership.md) and [Microsoft Purview](../purview.md); use [Copilot Studio agent governance](../../admin-and-governance/govern-copilot-studio-agents.md) when an agent becomes an organizational service.
