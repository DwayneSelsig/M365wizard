# Automate Ongoing Work With Autopilot

Consider Autopilot when a process needs continued attention, such as watching project updates and preparing follow-ups over several days. Start with a clear process and an accountable owner. Use [Copilot Cowork](./delegate.md) when you mainly need to assign and review a defined task.

Microsoft describes Autopilot as a proactive, persistent agent that takes an ongoing responsibility. Its [September 25, 2026 announcement](https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/) describes cloud hosting, its own identity and workspace, and access to work in Microsoft 365 within assigned permissions. [Microsoft's Autopilot learning module](https://learn.microsoft.com/en-us/training/modules/delegate-ongoing-work-autopilot-copilot/) explains the ongoing-work pattern and Frontier preview prerequisites.

## Agree On Authority And Review

Define the goal, information sources, permitted actions, approval points, and when the agent must ask a person for help. For example, let it prepare review material from approved project updates, with a person checking changes before messages go to stakeholders.

Assign a process owner to review results and changed business rules. IT must review the agent's access and the available audit and administration controls for the preview. Agree who can stop its work and remove access when the responsibility ends. See [Permissions And Ownership](../../admin-and-governance/permissions-and-ownership.md).

:::warning[Keep A Person Accountable]

An agent that continues working needs an owner who checks its activity, errors, and spending. Set approval points for messages, record changes, and other consequential actions.

:::

## Check Whether You Need A Persistent Agent

Cowork also supports recurring work through scheduled tasks, as described in [Microsoft's Cowork learning path](https://learn.microsoft.com/en-us/training/paths/delegate-work-with-copilot-cowork/). Use an existing scheduled task when that meets the need. Consider Autopilot when the responsibility requires ongoing attention and proactive follow-up. For an organizational agent with a managed release and support process, compare [Agent Builder and Copilot Studio](./build.md).

## Plan Around Preview Access And Usage

Autopilot is a preview experience. The September announcement describes a private preview; Microsoft Learn requires Frontier participation and an active Copilot license. Confirm the access offered to your organization before planning a rollout. Microsoft also places Autopilot under [usage-based billing with Copilot Credits](https://learn.microsoft.com/en-us/microsoft-365/copilot/user-subscription-license-usage-based-billing). Set a pilot budget and review consumption with the owner using [Licensing And Costs](./licensing-and-costs.md).
