# OneDrive

Use OneDrive for work files that you own, including drafts you share for feedback. Move a file to an owned Team or SharePoint site when colleagues need to maintain it as part of their regular work.

## Best For

Use OneDrive for drafts, personal work documents, notes, and short-term review by specific people. A file shared for comments remains personally owned.

## When To Move The File

Move the file when several people maintain it, a process depends on it, or it must remain available after its original owner changes roles. Put ongoing team work in the Team's SharePoint site. Put approved information for a wider internal audience in an owned SharePoint site. Microsoft's [file storage guidance](https://learn.microsoft.com/en-us/microsoft-365/admin/setup/set-up-file-storage-and-sharing) distinguishes occasional sharing from files with shared ownership.

The file owner and the receiving team or site owner should agree on the destination. Move the working file, confirm that the right people can open it, and point collaborators to its new location. Check links and any process that refers to the old location. Use [Where Should This File Live?](../decisions/where-should-this-file-live.md) to choose the destination.

:::warning[Avoid Two Working Copies]

After the move, do not keep both copies open for editing. Colleagues may continue working in the old file.

:::
