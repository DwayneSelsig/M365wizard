# Planner

Use Microsoft Planner when a team needs to assign work, set due dates, and follow progress. Choose the plan type from the work the team must manage.

## Best For

Use a basic Planner plan for team task boards, checklists, campaign work, small projects, and recurring operational tasks.

## Choose A Basic Or Premium Plan

Start with a basic plan when assignments, due dates, and a board give the team enough control. Consider a premium plan when the work needs dependencies, milestones, or a timeline. Features differ by plan type, and access to some features depends on the user's subscription. Check Microsoft's [current basic and premium comparison](https://support.microsoft.com/en-us/planner/compare-microsoft-planner-basic-vs-premium-plans) before choosing or changing a plan.

## Keep Tasks Connected To Their Work

Keep the plan with the Team that owns the work. Agree who maintains the plan, reviews overdue tasks, and closes it when the work ends. If an item is mainly a record to maintain over time, keep it in [Lists](./lists.md) and create a Planner task for the action it requires.

:::warning[Check Existing Connections]

Before changing a basic plan to premium, check any apps or workflows that use it. Microsoft says [connections built for basic plans may need changes](https://support.microsoft.com/en-us/planner/compare-microsoft-planner-basic-vs-premium-plans).

:::
