# Your Calendars

Use the calendar view to scan events from several sources.
Each color and source label helps identify where an item came from.

![Calendar view with multiple sources](/img/tools/my-calendars/calendar-overview.png)

## Show Or Hide A Calendar

Open **Settings** to see the source sections.

![The Settings button next to the search box](/img/tools/my-calendars/settings-button.png)
Use the eye control beside an optional calendar to change its visibility.
Some sections also have a bulk visibility control.
Mandatory calendars remain visible.

![Personal calendar settings](/img/tools/my-calendars/personal-settings.png)

If you see an item you cannot open, ask the source owner to check your access.
The web part does not grant source permissions.

## Open An Item

Select an event to view its available details.
The panel may show its time, location, description, and source.
Select **Open** to visit the original item when a link is available.
Teams Shifts do not have a reliable link to an exact shift.

## Search Events

Use **Search appointments** to match event titles or locations.
Clear the search box to show the current view again.

![Search results for calendar events](/img/tools/my-calendars/appointment-search.png)
