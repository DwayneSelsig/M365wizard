# Calendar Views

Choose Day, Week, or Month to match the planning question.
The view changes what you see, not the source data.

## Choose A View

Select **Day**, **Week**, or **Month** near the top of the calendar.
Use **Today**, the date field, or the arrows to move through dates.
The web part remembers your selected view in your personal settings.

![Month view](/img/tools/my-calendars/view-month.png)

![Week view](/img/tools/my-calendars/view-week.png)

![Day view](/img/tools/my-calendars/view-day.png)

## Find An Appointment

Search matches appointment titles and locations.
It does not search every field in an event.
Clear the text to return to the selected date range.

![Search calendar appointments](/img/tools/my-calendars/appointment-search.png)

## Open Event Details

Select an event to see details available from its source.
Use **Open** when the panel provides a link.
The link opens the original service or item.
