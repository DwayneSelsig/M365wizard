# Collect Information

Information collection can be simple or operational. Choose the tool based on what happens after submission.

## Recommended Pattern

Use Forms for simple collection. Use Lists when submitted information becomes a record that needs tracking, or when the team enters records directly. Add Planner when a record creates work for someone.

## Examples

Use Forms for event registrations, feedback, and quick requests. Use Lists for asset tracking, issue registers, or content inventories. Use Planner when each item needs an owner, due date, status, and follow-up.

## Watch The Handoff

Name the person who reviews submissions and moves a response to Lists or creates a Planner task when needed. If automation handles that handoff, give someone responsibility for checking failures and missed requests.
